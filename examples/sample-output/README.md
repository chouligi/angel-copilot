# Sample Output Placeholders

This folder documents expected output artifacts for both Angel Copilot workflows.

## Structure

- `quick-deal-memo/`
  - Example reference for single-deal memo output (Markdown).
- `unified-action-assessment/`
  - Version 4 example showing PURSUE / WAIT / PASS with a single recommendation.
- `screening-assessment/` and `dealflow-triage/`
  - Historical examples; their original schema and labels are intentionally preserved.

## Why placeholders

The repository ships synthetic examples for `v0.1.0` release readiness. Replace or augment these files with richer synthetic outputs over time.

The `screening-assessment/` sample demonstrates the current version 4 action recommendations. Older sample folders retain their original schema and terminology to illustrate historical report compatibility.

## Data policy

- Do not add real company documents or sensitive deal data.
- Keep sample outputs synthetic, anonymized, and clearly marked as examples.
